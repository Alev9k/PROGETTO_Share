Functional Requirements:

1. Il sistema deve permettere l'accesso agli utenti tramite l'inserimento di credenziali univoche.
2. Il sistema deve permettere l'identificazione del profilo dell'utente Operator o Technician che accede al gruppo*, al fine di abilitare le specifiche funzionalità associate.
3. Il sistema deve permettere all'Admin di creare gruppi di lavoro definendo la durata della giornata operativa.
4. Il sistema deve permettere all'Admin di invitare nuovi membri a partecipare a un gruppo tramite la generazione di un codice di accesso univoco.
5. Il sistema deve permettere all'Admin di definire degli asset*.
6. Il sistema deve permettere all'Admin di creare varie istanze di qualsiasi tipologia di asset già definita.
7. Il sistema deve permettere all'Operator di prenotare un bene* solo per le fasce orarie disponibili in una data specifica, escludendo i periodi già occupati.
8. Il sistema deve permettere all'Operator di prenotare un bene per una data futura entro un limite massimo di sette giorni.
9. Il sistema deve permettere all'Operator di compilare il report di riconsegna al termine di ogni sessione di utilizzo.
10. Il sistema deve fornire al Technician l'elenco dei beni che necessitano di riparazione, ordinati in base alla loro priorità.
11. Il sistema deve permettere al Technician di consultare i report di riconsegna di ogni bene che necessita di riparazione.
12. Il sistema deve permettere al Technician di segnalare l'avvenuto ripristino della funzionalità di un bene per renderlo nuovamente disponibile.
13. Il sistema deve permettere all'Admin di bloccare le prenotazioni di un bene.
14. Il sistema deve permettre all'Admin di inibire la capacità di un Operator di effetuare prenotazioni su ogni bene del gruppo.
15. Il sistema deve bloccare immediatamente le prenotazioni su un bene segnalato guasto, ed eliminare le prenotazioni già effettuate a suo carico.
16. Il sistema deve notificare agli Operator che la loro prenotazione su un bene guasto è stata eliminata.

Gruppo = insieme composto da un Admin, vari Operator e un Technician.
Asset = tipologia di ogetto messo a disposizione del gruppo, composto da:
  1. Nome
  2. Priorità*
  3. Report di riconsegna*
  4. Durata massima di utilizzo
Priorità = indice che discrimina l'importanza del bene in riparazione.
Report di riconsegna = Form creato dall'Admin con domande relative allo stato del bene.
Bene = istanza di un asset, possiede un nome ed eredita le specifiche dell'asset di appartenenza.
